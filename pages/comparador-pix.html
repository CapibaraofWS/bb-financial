Comparador PIX 🇧🇷

Cotizaciones de PIX (BRL ↔ ARS / USDT) en vivo de 25+ proveedores: Fiwind, Belo, Lemon, Mercado Pago, Ualá, Astropay y más. Datos en tiempo real vía API de ComparaPix.ar.

ℹ️ Sobre esta herramienta — qué muestra, supuestos y limitaciones

¿Qué es PIX? Sistema de pagos instantáneos de Brasil (Banco Central do Brasil, 2020). Permite enviar dinero entre cuentas usando una llave (CPF, email, teléfono o QR). Para argentinos viajando a Brasil, es la forma más eficiente de pagar en BRL.

Qué datos usa: cotizaciones de 25 proveedores (Fiwind, Belo, Lemon, Mercado Pago, Ualá, etc.) vía API pública de api.comparapix.ar, en tiempo real. Tomamos el precio de venta (lo que pagás vos) en ambos pares: BRL/ARS (cuánto pagás por un real) y BRL/USDT (con dólares cripto).

Cómo calcular cuánto recibís:

  • Si tenés ARS: BRL_recibís = ARS_gastás / sell_BRLARS (donde sell es lo que el proveedor cobra por 1 BRL)
  • Si tenés USDT: BRL_recibís = USDT_gastás / sell_BRLUSDT

Spread: diferencia entre buy y sell del proveedor — es lo que se queda como comisión implícita. Cuanto menor, mejor para vos.

Supuestos:

  • Tomamos las cotizaciones tal como las publica cada proveedor — no incluimos comisiones bancarias adicionales (transferencia, IVA, etc.) que cada exchange puede cobrar aparte.
  • "Mejor tasa" se determina por el menor spread, no por la mejor cotización aislada (que puede estar inflada).
  • Algunos proveedores ofrecen PIX directo, otros requieren conversión vía USDT primero. La columna isPix indica método directo.

Limitaciones:

  • No incluye comisiones bancarias por transferir de tu banco a la billetera/exchange.
  • Las tasas cambian minuto a minuto — refrescá la página para ver el último valor.
  • Algunos proveedores aplican límites mensuales o requieren KYC. Verificá en la app antes de operar.

⚠ NO es recomendación de inversión ni de uso. Es una herramienta informativa. La elección del proveedor depende de tu situación (residencia, KYC, monto, urgencia). Verificá siempre en la app/sitio oficial antes de operar.
